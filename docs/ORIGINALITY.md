# Roblox Originality Preflight

For greenfield game work, Roldex should use live research before committing to a name or a strongly defined concept.

The purpose is to reduce accidental duplication, not to find something to clone.

Roldex should check:

- exact proposed game/experience name
- close spelling/name variants
- strongly similar core mechanic combinations
- similar progression loops and player fantasy
- obvious branding confusion

Roldex should then preserve or introduce meaningful differentiators in gameplay, presentation, progression or social structure when overlap is high.

A search result is not proof that a name is legally available, trademark-safe or globally unique. Roldex should describe this as a collision/originality preflight rather than a legal clearance.
